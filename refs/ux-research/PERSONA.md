## P1 — 라이트 시청자 (둘러보러 온 신규)  ↔ UT 페르소나: **초보자**

| 항목 | 내용 | 신뢰도 |
|---|---|---|
| 한 줄 정의 | 게임 방송을 가볍게 둘러보러 온 신규·라이트 시청자 | 🟢 인접 실증 |
| 목표 | 지금 볼 만한 라이브를 빠르게 발견해 입장 | 🟢 인접 실증 |
| 곤경(pain) | 뭘 볼지 모름. 첫 화면이 비거나 느리면 즉시 이탈 | 🟢 인접 실증 |
| 행동 특성 | 추천·인기·게임별로 훑음. 로그인 전 탐색. 낮은 커밋 | 🟢 인접 실증 |
| **UT 시뮬레이션 매핑** | 느린 클릭(200~800ms)·잘못된 요소 선클릭 후 정정·에러 시 뒤로가기 | — |
| 실증 링크 | 인접: 스트리밍 신규 유입의 발견-중심 홈 행동(치지직/Twitch). 넥슨 IP 선호도는 🔵 | — |

## P2 — 헤비·도네이터 (팔로우 기반 충성 시청자)  ↔ UT 페르소나: **파워유저**

| 항목 | 내용 | 신뢰도 |
|---|---|---|
| 한 줄 정의 | 특정 스트리머를 팔로우·구독하고 후원하는 충성 시청자 | 🟢 인접 실증 |
| 목표 | 팔로우한 방송에 빠르게 재진입하고 후원·구독으로 참여 | 🟢 인접 실증 |
| 곤경(pain) | 팔로잉이 메인에서 안 보이면 매번 검색. 방송 시작을 놓침 | 🟢 인접 실증 |
| 행동 특성 | **팔로우 기반 재방문**, 긴 세션, 알림 의존, 후원/구독 적극 | 🟢 인접 실증 |
| **UT 시뮬레이션 매핑** | 빠른 클릭(50~150ms)·키보드 단축키·직접 경로 탐색 | — |
| 실증 링크 | 인접: 스트리밍 리텐션이 팔로우·구독 동선에 좌우됨(공개 벤치마크). 세션 길이·후원 전환율은 🔵 | — |

## P3 — 접근성 사용자  ↔ UT 페르소나: **접근성 사용자**

| 항목 | 내용 | 신뢰도 |
|---|---|---|
| 한 줄 정의 | 스크린리더·키보드 전용 내비게이션 + 자막 의존 사용자 | 🟢 인접 실증(WCAG) |
| 목표 | 키보드만으로 발견~시청 전 과정 수행, 자막으로 내용 파악 | 🟢 인접 실증(WCAG) |
| 곤경(pain) | ARIA 미흡·포커스 순서 혼란·자막 부재·장시간 흰 배경 눈 피로 | 🟢 인접 실증(WCAG) |
| 행동 특성 | Tab/Enter/Arrow 전용, 화면 낭독 의존, 다크·자막 선호 | 🟢 인접 실증 |
| **UT 시뮬레이션 매핑** | Tab 순서 이동·Enter/Space 활성화·ARIA label·대비/터치타겟 검증 | — |
| 실증 링크 | WCAG 2.1 AA 표준(검증된 기준). 대상 서비스 실제 적용은 직접 테스트로 검증 필요 | — |

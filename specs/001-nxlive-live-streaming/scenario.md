## 3. 사용자 행동 흐름 (✅ 사용자 확정)

```
[진입] ──▶ 홈에서 라이브 목록 훑기 (J1)
              │
              ├─ 게임 카테고리로 좁히기 (J2) ─┐
              │                              ├──▶ 라이브 카드 선택
              └─ 랭킹에서 바로 선택 ──────────┘
                                                │
                                                ▼
                                   ★ 라이브 시청 (J3)
                                   ★ 채팅 참여 (J4)
                                   시청자·채널 정보 확인 (J5)
                                                │
                              ┌─────────────────┼─────────────────┐
                              ▼                 ▼                 ▼
                     팔로우 (J6)        채널 페이지 이동 (J7)    이탈
                              │                 │
                              │                 ├─ 클립 재생 (J8)
                              │                 └─ 다른 라이브 발견 → 홈 복귀
                              │
                              └─ 재방문 시: 홈 → 팔로우 스트리머 직행

[별도 진입] 검색 (J9)
              │
              ├─ 라이브 결과 → 시청 페이지 (J3)
              ├─ 채널 결과 → 채널 페이지 (J7)
              └─ 클립 결과 → 클립 재생 (J8)

[예외 경로]
  · 검색 결과 없음 → 빈 상태 + "다른 키워드로 검색" 안내
  · 라이브 종료됨 → 시청 페이지에서 "방송 종료" 표시 + 채널 페이지로 유도
  · 네트워크 실패 → 재시도 안내
```

## 4. 페르소나별 과업 시나리오

### P1 라이트 시청자 — 처음 들어와 볼 만한 라이브를 찾아 시청

| 단계 | 트리거 | 행동 | 기대 결과 | 성공조건 |
|---|---|---|---|---|
| 1 | 추천 링크/검색으로 유입 | 홈 페이지 진입 | 라이브 카드 그리드가 즉시 표시 | LCP < 2.5s, 카드 ≥ 1개 노출 |
| 2 | 흥미 있는 게임이 눈에 안 띔 | 게임 카테고리 필터 선택 (J2) | 선택한 게임의 라이브만 표시 | 필터 적용 < 300ms |
| 3 | 마음에 드는 방송 발견 | 라이브 카드 클릭 (J1→J3) | 라이브 시청 페이지 진입, 플레이어 로드 | 페이지 전환 완료, 플레이어 표시 |
| 4 | 방송이 재미있음 | 채팅창에 메시지 입력·전송 (J4) | 메시지가 채팅에 표시 + 자동 유입 메시지 흐름 | 전송 후 1s 내 표시 |
| 5 | 스트리머가 궁금 | 채널명 클릭 (J7) | 채널 페이지: 상태·팔로워·소개·클립 | 채널 정보 완전 로드 |
| 6 | (선택) 클립 탐색 | 클립 카드 클릭 (J8) | 클립 재생 진입 | 재생 가능 상태 |

- 분기/실패: 검색 결과 없음 → 빈 상태 + 안내 문구 / 라이브 종료 → "방송 종료" + 채널 유도

### P2 헤비·도네이터 — 팔로우한 스트리머 방송에 빠르게 재진입

| 단계 | 트리거 | 행동 | 기대 결과 | 성공조건 |
|---|---|---|---|---|
| 1 | 팔로우 스트리머 방송 시작 알림/습관 | 홈 진입 | 팔로우 중인 라이브가 상단에 노출 | 팔로우 라이브 ≥ 1 표시 (있는 경우) |
| 2 | 목표 스트리머 확인 | 팔로우 라이브 카드 바로 클릭 (J1→J3) | 시청 페이지 직행 | 클릭 → 시청 2스텝 이내 |
| 3 | 방송 시청 중 | 채팅 적극 참여 (J4) | 빠른 속도로 다수 메시지 전송 | 연속 전송 가능, 지연 없음 |
| 4 | 스트리머 응원 | 팔로우 버튼 확인/토글 (J6) | 팔로우 상태 즉시 반영 | 토글 후 UI 즉시 갱신 |
| 5 | 이전 하이라이트 확인 | 채널 → 클립 (J7→J8) | 과거 클립 목록 + 재생 | 클립 로드 완료 |
| 6 | 다른 방송 탐색 | 검색 (J9) | 라이브/채널/클립 탭별 결과 | 탭 전환 즉시, 결과 정확 |

- 분기/실패: 팔로우 스트리머 없음 → 빈 팔로잉 + "스트리머를 팔로우해보세요" / 네트워크 실패 → 재시도 안내

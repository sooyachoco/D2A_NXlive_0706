## 초보자 시나리오 (P1 라이트 시청자)

### S-B01: 홈 → 라이브 발견 → 입장
- **맥락**: 퇴근 후 "지금 뭐 재밌는 방송 하나" 둘러보러 처음 방문.
- **목표**: 볼 만한 라이브를 찾아 시청 화면에 입장.
- **성공 조건**: 라이브 카드 클릭 후 `/live/*` 시청 화면(플레이어+채팅) 표시.
- **여정**: 진입(홈) → 카드/랭킹 훑기 → 카드 클릭 → 시청 진입.
- **Playwright 재현**: 카드 로딩 대기, 느린 클릭, 첫 카드 진입, 플레이어·채팅 가시성.
- **이탈 관찰**(JOURNEY 1·2단계 ⚠): 빈/느린 첫 화면, 발견 실패.

### S-B02: 게임 필터로 좁히기
- **맥락**: 메이플스토리만 보고 싶다.
- **목표**: 특정 게임 라이브만 걸러 보기.
- **성공 조건**: 게임 태그 클릭 시 카드 그리드가 해당 게임만 표시.
- **Playwright 재현**: 필터 버튼 클릭 → 카드 수·내용 변화 확인.

## 파워유저 시나리오 (P2 헤비·도네이터)

### S-P01: 시청 진입 → 팔로우 → 채팅 참여
- **맥락**: 즐겨보는 스트리머 방송에 빠르게 들어가 참여.
- **목표**: 시청 화면에서 팔로우하고 채팅 전송.
- **성공 조건**: 팔로우 버튼이 "팔로잉"으로 전환 + 전송한 채팅이 목록에 노출.
- **여정**: 홈 히어로/랭킹 → 시청 → 팔로우 → 채팅.
- **Playwright 재현**: 빠른 클릭, 팔로우 토글 상태 변화, 채팅 입력·전송·반영.
- **이탈 관찰**(4단계 ⚠): 참여(팔로우) 마찰.

### S-P02: 검색으로 직접 도달
- **맥락**: 특정 게임/스트리머를 바로 찾는다.
- **목표**: 검색어로 라이브/채널/클립 탭 전환하며 결과 확인.
- **성공 조건**: 검색어 입력 시 결과 필터링 + 탭 전환 동작.
- **Playwright 재현**: 검색 입력, 탭 클릭, 결과 수 변화.

## 접근성 사용자 시나리오 (P3)

### S-A01: 키보드 전용 홈 탐색
- **목표**: 마우스 없이 Tab/Enter로 홈 내비·필터 조작.
- **성공 조건**: 포커스 이동 요소 ≥ 6, 필터 버튼 `aria-pressed` 노출, focus outline 가시.
- **Playwright 재현**: Tab 반복 → 포커스 요소 카운트, aria-pressed 속성, outline 계산.

### S-A02: 시청 화면 폼·컨트롤 접근성
- **목표**: 채팅 입력·전송·팔로우가 접근 가능한 이름을 가진다.
- **성공 조건**: 채팅 input에 `aria-label`, 버튼에 접근 가능 이름 존재.
- **Playwright 재현**: `getByLabel('채팅 입력')`, 버튼 role/name 확인.

## 결함 목록 (우선순위 순)

### [F-001] 하이드레이션 완료 전 초기 인터랙션이 조용히 무시됨
- **Severity**: S3 — Major
- **휴리스틱**: N1 시스템 상태 가시성
- **영향 페르소나**: 파워유저(P2, 즉시 조작) > 초보자
- **발생 화면·경로**: 라이브 시청(팔로우·채팅 전송), 홈(게임 필터), 검색(키워드 필터) — 로드 직후 수백 ms
- **관찰된 증상**: S-P01 354ms 초고속 조작 시 팔로우·채팅 모두 무반응(완료 실패). S-B02/S-P02도 즉시 조작 시 필터 미반영(7→7).
- **근본 원인**: 클라이언트 컴포넌트 하이드레이션 완료 전에는 onClick/onChange 핸들러가 바인딩되지 않는다. 이 창 동안 클릭이 DOM엔 닿지만 동작하지 않고, **로딩/비활성 등 진행 상태 표시가 없어** 사용자는 무시된 사실을 인지하지 못한다. (기능 자체는 정상 — e2e는 정상 대기 시 전부 통과.)
- **개선 방향**: 하이드레이션 전까지 주요 인터랙티브 컨트롤에 로딩/스켈레톤 또는 `disabled` 표시. 최소한 시청 페이지 진입 시 스켈레톤. (Next 15 first-load 창은 짧지만 P2 초고속 사용자에게 실재.)
- **스크린샷**: power-S-P01-follow-chat.png

### [F-002] 팔로우한 채널을 다시 찾을 동선(팔로잉 뷰)이 없음
- **Severity**: S3 — Major
- **휴리스틱**: N6 기억보다 인식 / N7 효율
- **영향 페르소나**: 파워유저(P2 헤비·도네이터)
- **발생 화면·경로**: 전역 — 헤더 내비(라이브/클립/검색)에 "팔로잉" 없음
- **관찰된 증상**: 팔로우 상태는 localStorage로 지속되나(F-09), 팔로우한 채널을 모아 보거나 재진입할 화면이 없다.
- **근본 원인**: USER_JOURNEY_MAP 5단계(재방문)는 P2 리텐션의 핵심(팔로잉 최상단)인데 MVP 페이지 목록(홈/시청/채널/클립/검색)에 팔로잉 뷰가 빠짐.
- **개선 방향**: 헤더에 "팔로잉" 추가 + 홈 상단 "팔로잉" 레일(팔로우 채널의 라이브 우선 노출). **범위 참고**: spec MVP 밖 → 다음 이터레이션 권장.
- **스크린샷**: —

### [F-003] 라이브 시청 진입 시 로딩 상태 부재
- **Severity**: S2 — Minor
- **휴리스틱**: N1 시스템 상태 가시성
- **영향 페르소나**: 초보자
- **관찰**: 플레이어가 즉시 플레이스홀더로 뜨는 것은 양호하나, 실제 영상/데이터 로딩 시 스켈레톤이 없어 Phase 2(실 API) 전환 시 빈 화면 위험.
- **개선 방향**: `loading.tsx`(App Router) 또는 스켈레톤 도입. Phase 2 착수 시 필수.

### [F-004] 전환적 하이드레이션 경고 (비재현)
- **Severity**: S2 — Minor
- **휴리스틱**: N1 / 기술 안정성
- **관찰**: a11y 페르소나 급속 키보드 조작 중 콘솔 하이드레이션 경고 1건. **깨끗한 재로드 5/5 페이지에서는 0건**(ko-KR 로케일 고정 수정 이후 결정적 불일치 해소됨).
- **근본 원인 추정**: zustand persist 리하이드레이션 또는 조작-하이드레이션 레이스. 비재현이라 관찰만.
- **개선 방향**: 재발 시 persist `skipHydration` + 명시적 rehydrate, 또는 클라이언트 전용 값 `suppressHydrationWarning`. 현재는 모니터링.

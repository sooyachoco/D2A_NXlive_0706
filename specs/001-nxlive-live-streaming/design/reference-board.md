### NX Basic 컴포넌트 매핑 (전 화면 공통)

| 화면 | NX Basic 컴포넌트 | 용도 |
|---|---|---|
| 라이브 시청 | TextField `size="m"` + Button `variant="filled"` + 리스트 스크롤 | 채팅 입력·전송·메시지 목록 |
| 홈 | Tag `variant="filled"` + Card hover 패턴 | 게임 카테고리 필터 + 라이브 카드 |
| 채널 | Tab `variant="underline"` + Button `semanticColor="primary"` | 클립/정보 탭 전환 + 팔로우 |
| 검색 | TextField `placeholder` + Tab 3종 | 검색 입력 + 결과 탭 |
| 클립 | Card 패턴 + 텍스트 계층 | 클립 카드 그리드 |

## 3. 미결 (와이어프레임에서 확정할 것)

- 라이브 시청 페이지의 채팅 영역 높이 — 플레이어 비율(16:9)과 채팅 영역의 정확한 높이 배분은 ui-design-workflow STEP 3 발산에서 해소
- 클립 페이지 정렬 옵션 (인기/최신/조회수) — MVP에서 단순 최신순만 할지 정렬 UI를 넣을지

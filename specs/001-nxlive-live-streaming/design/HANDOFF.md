# 개발 핸드오프 — NXlive 게임 라이브 스트리밍 MVP

> 출처: design-handoff 스킬 · 2026-07-06 · UT 통과(S4=0) 확인
> 입력: spec.md · scenario.md · reference-board.md · design-direction.md · UT_FINDINGS_REPORT.md

## 1. 개요 · 범위

- **대상**: NXlive MVP — 5개 페이지 (홈 · 라이브 시청 · 채널 · 클립 · 검색)
- **라우트**: `/` · `/live/:channelId` · `/channel/:channelId` · `/clips` · `/search`
- **수용 기준**: 모든 F-01~F-10 기능 구현 · Mock 데이터 기반 · UT S4=0 통과
- **인증**: 없음 (none) · 팔로우는 로컬 상태(localStorage)
- **메인 기능**: ★ 라이브 시청 `/live/:channelId` — 비디오 플레이어 + 실시간 채팅 + 시청자 카운트

## 2. 화면별 레이아웃

### 홈 `/`
- **구조**: 상단 다크 히어로(현재 LIVE 대표 1개) + 카테고리 레일(게임별 Tag) + 하단 라이트 카드 그리드
- **그리드**: 콘텐츠 max-width 1440px · 카드 3~4열 반응형 · 랭킹 사이드 패널(데스크톱)
- **참고 키스톤**: 치지직 메인 — 히어로+카드 레일+랭킹

### ★ 라이브 시청 `/live/:channelId`
- **구조**: 좌측 플레이어 ~70% / 우측 채팅 ~30% (2칼럼)
- **플레이어 아래**: 채널 정보 바 (아바타 · 채널명 · 시청자 수 · 팔로우 버튼)
- **채팅**: 메시지 리스트(자동 스크롤) + 하단 고정 입력 (TextField + 전송 Button)
- **참고 키스톤**: 치지직 라이브 시청 — 70/30 비율, 채팅 하단 고정

### 채널 `/channel/:channelId`
- **구조**: 상단 프로필 영역(아바타 · 채널명 · 팔로워 수 · LIVE/OFFLINE 뱃지 · 소개 · 팔로우 버튼) + 하단 클립 카드 그리드
- **참고 키스톤**: 치지직 채널 — 배너+프로필+클립 그리드

### 클립 `/clips`
- **구조**: 카드 그리드(썸네일 16:9 + 제목 + 스트리머 + 조회수) · 최신순 정렬
- **참고 키스톤**: Twitch Clips — 카드 그리드+재생 시간 오버레이

### 검색 `/search`
- **구조**: 상단 검색바(TextField) + 탭 3종(라이브 · 채널 · 클립) + 결과 카드 그리드
- **빈 상태**: "검색 결과가 없습니다" + 안내
- **참고 키스톤**: 치지직 검색 — 검색바+탭+결과 카드

## 5. 인터랙션 · 상태 전이

| 트리거 | 동작 | 결과 | 성공조건 (scenario.md) |
|---|---|---|---|
| 카테고리 Tag 클릭 | 필터 적용 | 해당 게임 라이브만 표시 | 필터 적용 < 300ms |
| 라이브 카드 클릭 | 페이지 전환 | `/live/:id` 진입 | 플레이어 표시 |
| 채팅 메시지 전송 | 입력 클리어 + 메시지 추가 | 채팅 리스트에 메시지 표시 | 전송 후 1s 내 표시 |
| 팔로우 버튼 토글 | localStorage 갱신 + UI 토글 | filled↔outline 전환 | 즉시 UI 갱신 |
| 검색어 입력 + Enter | 결과 조회 | 탭별 결과 카드 표시 | 탭 전환 즉시 |
| 채널명 클릭 | 페이지 전환 | `/channel/:id` 진입 | 채널 정보 완전 로드 |

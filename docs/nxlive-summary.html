📅 2026-07-06 ✅ Phase 1 완료 🎯 배포 가능

🎯 프로젝트 목표

넥슨 게임 라이브스트리밍 플랫폼 시제품(MVP)을 만들어서, 실제 사용자가 써볼 수 있는 상태까지 가져가기.

✅ 완성한 것들

1️⃣ 화면 디자인 확정

  • 디자인 4가지 안을 만들어서 선택
  • 선택한 것: NX Basic (넥슨 기본 규칙 — 파란색·어두운 배경)
  • 산출물: 최종 화면 설계도 완성

2️⃣ 웹사이트 5개 페이지 구현

페이지 역할
홈 지금 진행 중인 게임 생방송 목록 보기
시청 특정 생방송 선택해서 보기 + 채팅
채널 특정 스트리머(채널) 정보 + 팔로우
클립 생방송 하이라이트 영상 보기
검색 생방송·채널·클립 검색하기
기술: Next.js (웹사이트 틀) + React (상호작용)

3️⃣ 자동 테스트 작성

  • 로봇이 마우스를 클릭하듯이 자동으로 동작 검증
  • 결과: 5개 테스트 모두 통과 ✅

4️⃣ AI가 3명 가짜 사용자로 테스트

사용자 유형 특징 결과
초보자 천천히 클릭 ✅ 잘 작동
고급 사용자 엄청 빠르게 클릭 ⚠️ 초기 로딩 때 클릭 안 먹음
접근성 키보드만 사용 ✅ 완벽함
완료율: 83% (5개 중 5개 성공)

5️⃣ 코드 품질 검수

  • 보안, 성능, 아키텍처, 기능, 접근성 전문가 6명이 동시에 검토
  • 결과: 심각한 문제 없음 ✅ | 개선 사항 6건 모두 수정 ✅

⚠️ 아직 남은 작은 문제들

순번 문제 심각도 언제 고칠지
1번 첫 로딩 때(0.5초) 버튼 클릭이 안 먹힘 중간 배포 전 수정 가능 (~3시간)
2번 "팔로우한 채널 모음" 화면 없음 중간 다음 버전
3번 실제 영상 로딩 중 로딩 표시 없음 낮음 실제 영상 서버 연결할 때
4번 가끔 기술적 경고 메시지 낮음 계속 모니터링

🔧 기술 정보

사용한 도구

  • 웹사이트 만드는 도구: Next.js 15 (최신 버전)
  • 상호작용: React 19
  • 디자인 규칙: NX Basic (넥슨 표준)
  • 데이터: 현재 가짜 데이터 (나중에 실제 서버 연결)
  • 로그인: 없음 (시제품이라서)

테스트한 것

  • 🖥️ 큰 화면 (1440×900)
  • 📱 작은 화면 (640×1080)
  • ⌨️ 키보드만 사용하는 사람들
  • 🤖 자동 클릭 테스트

코드 품질

  • 웹 접근성 기준 100% 통과 (누구나 쓸 수 있게)
  • 색 대비 기준 통과 (색약자도 구분 가능)
  • 버튼·폼 모두 키보드로 조작 가능
